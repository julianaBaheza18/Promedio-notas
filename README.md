# Promedio de notas
**Nombre del estudiante:** Juliana Baheza
## Descripción
Este proyecto contiene un programa en Python que permite calcular el promedio de dos notas de un estudiante.
La función recibe dos notas como parámetros, realiza el cálculo del promedio y devuelve el resultado mediante return.
## Pseudocódigo
INICIO
FUNCION calcularPromedio(nota1, nota2)
    promedio ← (nota1 + nota2) / 2
    RETORNAR promedio
FIN FUNCION
nota1 ← 8
nota2 ← 9
resultado ← calcularPromedio(nota1, nota2)
IMPRIMIR resultado
FIN
